# cdn-caddy

Unmodified mirror of Caddy (Apache-2.0), kept by Computational Datanotes (compdatanotes.com) for its fetch server.

1. **Upstream:** https://github.com/caddyserver/caddy.git
2. **Branch `master`:** an exact copy of upstream; never edited here.
3. **Branch `ccn` (default):** only our own files: this README and the sync workflow.
4. **Rule:** none of the upstream files are changed unless the project goes out of business, changes to a closed licence, acts against its users, or its trust chain breaks (see `projects/ccn-chain-lab.md` in ccn-hoshino-and-colleagues).
5. Upstream files keep their own licence (Apache-2.0). Only the files on the `ccn` branch are ours.
